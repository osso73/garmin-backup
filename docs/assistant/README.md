# Assistant docs

This folder contains planning and tracking files created during assistant sessions.

## Files

- `docs/assistant/TASKS.md`
  - Clickable checklist of independent project improvements.

- `docs/assistant/DECISIONS.md`
  - Decision log for completed, skipped, or deferred tasks.

- `docs/development/README.md`
  - Plan and structure for maintainer/developer documentation.

## Suggested workflow

1. Pick one or more items from `docs/assistant/TASKS.md`.
2. Implement the selected tasks.
3. Mark completed tasks in `docs/assistant/TASKS.md`.
4. Record the rationale in `docs/assistant/DECISIONS.md`.
