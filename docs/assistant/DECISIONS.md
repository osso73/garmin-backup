# Decisions Log

Use this file to record which tasks were completed, skipped, or deferred, and why.

## How to Use

- Add one entry per decision.
- Link to the related task in `docs/assistant/TASKS.md`.
- Keep reasons short and concrete.

## Entry Template

```md
### YYYY-MM-DD - Task X
- Status: done | skipped | deferred
- Decision: One-line summary
- Reason: Why this choice was made
- Follow-up: Optional next action
```
